# Публикация на GitHub Pages

Весь проект хранится в публичном репозитории:
https://github.com/oas1230-crypto/lakeland-terrier

Готовый сайт находится в `site/`. Workflow `.github/workflows/pages.yml` публикует только содержимое этой папки. Эскизы, исследования, оригиналы и проверки доступны в репозитории, но не входят в публикуемый сайт.

## 1. Включите Pages вручную

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В **Build and deployment → Source** выберите **GitHub Actions**.

Не выбирайте **Deploy from a branch**: папка `site/` не доступна в списке папок этого режима. Создавать дополнительный workflow по шаблону не нужно — он уже есть в репозитории.

## 2. Запустите публикацию

1. Откройте **Actions**.
2. В списке слева выберите **Publish website**.
3. Нажмите **Run workflow**, выберите ветку **main** и подтвердите запуск.
4. Дождитесь успешного завершения.
5. Адрес опубликованного сайта появится в задании публикации и в **Settings → Pages**.

Ожидаемый адрес: https://oas1230-crypto.github.io/lakeland-terrier/

Workflow запускается только вручную. Создание репозитория и отправка коммитов сами по себе сайт не публикуют.

## 3. Проверьте сайт

Откройте сайт с компьютера и телефона. Проверьте навигацию, переключение семейных сцен, фотоальбом, изображения и видео у озера.

При ошибке публикации откройте журнал задания в **Actions**. Проверьте, что в Pages выбран **GitHub Actions**, запуск выполнен для ветки `main`, а файл `site/index.html` существует.

## 4. Как обновлять

Изменяйте файлы в локальной папке `site/`. Из корня проекта выполните:

```bash
git status
git add .
git commit -m "Update website"
git push
```

Затем повторите ручной запуск **Actions → Publish website → Run workflow**.

## 5. Прежний репозиторий

Прежний репозиторий: https://github.com/oas1230-crypto/Lakeland-Terrier.-Breed-Presentation

После проверки нового сайта владелец может удалить прежний репозиторий вручную. Удаление прежнего репозитория отключит прежний адрес GitHub Pages. Новый сайт будет иметь адрес, указанный выше.

Официальная документация: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Что входит в новую редакцию

В основе — выбранный вариант «01 · Внутри прогулки» с окончательными правками от 4 октября 2026 года. Первый экран: «Маленькая собака. Большой мир рядом.» и утверждённый крупный портрет с кадрированием слева. Это одна страница: английские корни и история породы, характер, забота, семейные сцены, личный фотоальбом, отдых на туристической стоянке у озера и материалы для дальнейшего знакомства.

Весь сайт работает на бесплатном GitHub Pages без команд сборки, внешних API и платных сервисов. Фотоальбом и переключатель сцен используют обычный JavaScript. Без JavaScript сцены видны подряд, а нажатие на фотографию открывает файл изображения.

В блоке у озера — личная фотография и видео `assets/media/lake-boardwalk.mp4` (около 17 секунд, H.264/AAC). Видео запускается кнопкой, до запуска отображается постер. Все файлы хранятся вместе с сайтом; отдельный видеохостинг не нужен. Старое видео реки убрано из публикационного комплекта.

Исходный MOV, оригиналы фотографий, эскизы и проверочные снимки в архив для публикации не включены.
