# Макеты второй редакции

Это локальные варианты для обсуждения. Текущий опубликованный сайт и настройки GitHub Pages не изменены. Исходники публикации в `site/` сохранены без изменений.

## Просмотр

Пока локальный сервер запущен: http://127.0.0.1:4175/

Верхний переключатель показывает исходное оформление, «Озёрные тропы», «Фотожурнал» и «Тихие минуты». При переключении сохраняется раздел, который вы смотрите. «Открыть отдельно» показывает выбранную страницу без панели сравнения.

После перезапуска компьютера откройте терминал в этой папке и выполните:

```sh
python3 -m http.server 4175 --bind 127.0.0.1
```

Затем откройте адрес выше. Сервер доступен только на этом компьютере. Страницы и изображения сохранены локально; аккаунт Stitch для просмотра не нужен.

## Что сохранено

- `original/` — локальная копия первого сайта, включая авторские фотографии и видео; по просьбе владельца исправлен только мобильный перенос главного заголовка.
- `story.html`, `story-trails.html` и `story-album.html` — три новых варианта с общей информацией, различными композициями, фонами и фотографиями первого экрана.
- `assets/stitch/` — все восемь одобренных изображений Google Stitch, включая спящего рыжего гризли у ботинка и рюкзака.
- `DESIGN.md` — решения по дизайну и ограничения качества изображений.
- `qa/` — снимки экрана и результаты проверок локальных файлов, адаптивности и интерактива.

Проверены новые варианты при ширине 360, 390, 768 и 1111 пикселей; горизонтального переполнения не обнаружено. Проверены клавиатурное переключение сцен, открытие и перелистывание фотографий, закрытие альбома клавишей Escape и переключение оформлений. Исходные файлы `site/` не изменены; локальная копия отличается исправленным мобильным переносом заголовка и версией ссылки на CSS.
