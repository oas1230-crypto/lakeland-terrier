# Сравнение фотографий первого экрана

Макет от 4 октября 2026 года: http://127.0.0.1:4173/sketches/hero-comparison/.

Кнопки переключают нынешнюю фотографию собаки на мху и крупный портрет из первой редакции сайта. По умолчанию открыт портрет. Параметры `?photo=current` и `?photo=new` открывают соответствующий вариант сразу. На телефоне фото находится над текстом. Без JavaScript оба экрана показаны последовательно.

Портрет: Srinayan Puppala (TigerPuppala), https://commons.wikimedia.org/wiki/File:Lakeland_Terrier_Flickr.jpg — CC BY-SA 2.0, https://creativecommons.org/licenses/by-sa/2.0/. Исходник `research/friend.jpg`, 800×533. Производная WebP; адаптивное кадрирование средствами CSS, без дорисовки. Текущий снимок на мху предоставлен владельцем.

Макет использует оформление и лесной фон из `../../site/`. Это отдельный эскиз; основной сайт и публикационный ZIP пока не изменены. Предыдущая проба со снимком в попонке снята с показа, файлы сохранены в assets.

## Вариант 03 — два фото

`?photo=duo`: портрет из первой редакции сверху, собака на мху снизу. Адаптивное кадрирование средствами CSS; по нажатию открывается полный снимок. Три варианта доступны в верхнем переключателе.

## Вариант 04 — в кресле

`?photo=chair`: личный снимок собаки в карповом кресле. Исходный JPEG 360×480; на больших экранах детализация ограничена.

Вариант 02 обновлён: фотография уменьшена, правый край полностью показан; слева сохранено кадрирование со стороны носа. Фото не дорисовывалось.
