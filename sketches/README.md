# Два эскиза фотоистории

Откройте `index.html` в браузере или http://127.0.0.1:4173/sketches/ при работающем локальном сервере.

- **01 · Внутри прогулки** — тёмно-зелёная фотоистория с крупным портретом, лесом под текстом и переходом к английским корням.
- **02 · Фотожурнал** — асимметричные развороты, светлая шалфейная зелень, тёмные природные блоки и альбом деталей.

В верхней панели можно переключать варианты. Фотографии открываются крупно; стрелки листают, Escape закрывает. Без JavaScript оба варианта видны последовательно, ссылки открывают сами изображения.

Это отдельные наброски, а не финальная версия для публикации. Окончательный сайт находится в `site/`, актуальный комплект публикации — `lakeland-github-pages.zip`. Эскизы используют некоторые материалы из соседней папки `site/assets/`, поэтому при переносе сохраните структуру папок. Все нужные файлы окончательного варианта уже включены в комплект GitHub Pages.

Никаких сборок, серверных функций, внешних API или платных сервисов нет. Сервер нужен только для удобного локального просмотра, сами страницы статические.

## Материалы

Присланные оригиналы сохранены в `originals/`, облегчённые WebP без EXIF — в `assets/`. Фотографии не дорисованы. Повтор одного и того же снимка собаки в лесу в подборку не включён. Видео сохранено как исходный материал. В обоих эскизах добавлен фрагмент реки: 10 секунд (03–13 с оригинала), MP4/H.264, 720×1280, 24 кадра/с, без звука, без автозапуска. Из видео извлечены два кадра для постера и фона; HDR переведён в SDR, метаданные съёмки в производных удалены. Место — Налибокская пуща, по сообщению владельца. Видеофайл загружается по запросу (preload=none). Никаких имён или кличек в подписях нет.

Фотографии владельца показывают современные прогулки, без указания места съёмки. Озерный край показан отдельным лицензированным снимком. Авторство и лицензия внешнего фото, а также пометки об ИИ-иллюстрациях доступны внизу страницы. Сам эскиз закрыт от индексации метатегом robots.
