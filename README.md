# Лейкленд-терьер — маленькая собака, большой мир

Окончательная редакция от 4 октября 2026 года: выбранная композиция «01 · Внутри прогулки» с утверждёнными правками.

## Готовый сайт

- `site/` — все файлы для публикации.
- `lakeland-github-pages.zip` — те же файлы в архиве, без внешней папки `site`.
- `site/ПУБЛИКАЦИЯ.md` — инструкция для ручного включения GitHub Pages и запуска публикации.
- `.github/workflows/pages.yml` — публикация папки `site/` через GitHub Actions по ручному запуску.
- `site/ИСТОЧНИКИ.md` — авторство фотографий, происхождение иллюстраций и видео, источники фактов.

Для просмотра откройте `site/index.html` в Safari или Chrome. Если работает локальный сервер проекта на порту 4173, адрес: http://127.0.0.1:4173/site/. Адрес 127.0.0.1 доступен только на этом компьютере и только пока сервер запущен. Для постоянного адреса опубликуйте содержимое `site/` через GitHub Pages.

## Что изменилось

Единая лесная зелёная палитра, крупные кадры, природные фоны под текстом. Заголовок первого экрана — «Маленькая собака. Большой мир рядом.», как в одобренном макете. На первом экране утверждён вариант 02: уменьшенный крупный портрет Srinayan Puppala, обрезанный слева, с сохранённым правым краем. Прежнее фото на мху перенесено в нижний большой кадр фотоальбома рядом с грибом. Фронтальный портрет на мху находится в фотоальбоме. История породы ведёт к разделам «Исследователь никуда не исчез» и «Любовь в повседневных делах». Сохранены три семейные сцены с переключением. Личные фотографии, включая снимки после тримминга, открываются и листаются в альбоме. Блок с рекой заменён отдыхом на туристической стоянке у озера: настил и собака в карповом кресле. Видео прогулки по настилу запускается по кнопке.

Навигация прокручивает одну страницу. Внешние ссылки ведут к источникам и породным организациям. Имена и кличка собаки не указываются, ИИ-иллюстрации подписаны.

## Файлы

`index.html` — содержание, `styles.css` — оформление и адаптивность, `script.js` — сцены, фотоальбом и мягкое появление изображений. В `assets/images/` хранятся материалы проекта, в `assets/owner/` — оптимизированные личные фотографии и постер, в `assets/media/` — видео прогулки по настилу.

Все ресурсы локальные, пути относительные. Сборка и установка пакетов не нужны. Основной рассказ работает без JavaScript. Поддерживаются клавиатурная навигация и настройка уменьшенного движения.

## Рабочие материалы

`sketches/` сохраняет два эскиза для сравнения; они используют часть изображений из `site/`. Оригиналы личных фотографий и MOV сохранены в `sketches/originals/`. `research/` содержит источники первоначальной подборки, `qa/final/` — итоговые проверки утверждённой редакции. Эти папки не нужно загружать на GitHub Pages.

Репозиторий проекта: https://github.com/oas1230-crypto/lakeland-terrier. Git отслеживает всю рабочую папку, включая сайт, исследования, эскизы, оригиналы и проверки. Служебные файлы macOS `.DS_Store` исключены.

Публикацию выполняет владелец самостоятельно: **Settings → Pages → Source: GitHub Actions**, затем **Actions → Publish website → Run workflow → main**. Workflow публикует только содержимое `site/`. Отправка коммита сама по себе публикацию не запускает; после обновления сайта запустите workflow снова.

Архив `lakeland-github-pages.zip` сохранён как ранее подготовленный комплект сайта; инструкции внутри архива относятся к прежнему способу ручной загрузки файлов.
