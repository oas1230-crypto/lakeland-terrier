# Лейкленд-терьер — четыре истории о жизни рядом

Вторая домашняя работа, 10 октября 2026 года. На одной странице можно переключать четыре оформления: **Исходное → Озёрные тропы → Фотожурнал → Тихие минуты**. По умолчанию открываются «Озёрные тропы»; выбранный вариант сохраняется в браузере.

Публичный адрес: https://oas1230-crypto.github.io/lakeland-terrier/

## Файлы для публикации и сдачи

- `site/` — готовый статический сайт со всеми четырьмя вариантами, локальными фотографиями, шрифтами и видео.
- `lakeland-homework-2.zip` — архив второй домашней работы: сайт, эта инструкция, описание дизайна и workflow GitHub Pages.
- `homework-2/` — сохранённые запросы и результаты Google Stitch, исходники MagicPath, локальные макеты и проверки.
- `.github/workflows/pages.yml` — публикация только `site/` через ручной запуск GitHub Actions.

Прежняя версия сайта сохранена в истории Git, начиная с коммита `4d139a0`. Архив `lakeland-github-pages.zip` относится к первой домашней работе. Оформление «Исходное» в новом сайте сохраняет прежний дизайн; единственная согласованная визуальная правка — перенос главного слогана на телефоне.

## Локальный просмотр

Из папки `site/` выполните:

```sh
python3 -m http.server 4175 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4175/. Если этот порт занят просмотром макетов `homework-2/prototype/`, используйте другой порт, например 4176. Закрытие приложения может остановить сервер; файлы проекта при этом сохраняются.

## Дизайн и инструменты

«Фотожурнал» и «Озёрные тропы» развивают направления Google Stitch. «Тихие минуты» — полная статическая адаптация компонента, разработанного и собранного через официальный плагин MagicPath. Новые иллюстрации получены в Google Stitch; они подписаны отдельно от авторских фотографий и видео. Типографика новых вариантов различается: Lora + Source Sans 3, Golos Text, PT Serif + PT Sans. WOFF2 и лицензии шрифтов сохранены локально.

Есть переключение сцен, открытие и перелистывание фотоальбома, клавиатурное управление и лёгкое увеличение изображений при наведении. На сенсорных устройствах подсказка открытия фото видна постоянно; уменьшение движения отключает анимацию. Исходные материалы первой работы находятся в `site/original/`, источники — в `site/original/ИСТОЧНИКИ.md`; происхождение новых ресурсов и проверки — в `homework-2/`.

## Публикация

GitHub Pages использует GitHub Actions. После отправки коммита на `main` запустите **Actions → Publish website → Run workflow → main**. Сам push публикацию не запускает. Сборка и установка пакетов не нужны; публикуется только содержимое `site/`.

Для ответа на домашнюю работу приложите `lakeland-homework-2.zip` и ссылку на опубликованный сайт выше.
